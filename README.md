# ✨ Uma em Uma Vida — Site de Pedido de Namoro Intergaláctico

Um site ultra-imersivo, surreal e interativo inspirado na música **"Uma em Uma Vida"**.

## Como usar

1. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Safari, Edge).
2. Ou sirva localmente:
   ```bash
   # Com Python
   python3 -m http.server 8080
   # Depois acesse http://localhost:8080
   ```

## Experiência

- **10 páginas** (incluindo a intro personalizada)
- Efeitos 3D com Three.js (globo intergaláctico)
- Animações com GSAP
- Música de fundo **"Uma em Uma Vida"** (ative o botão 🔊)
- Sons procedurais de UI
- Confetes e celebração épica
- Botão "Esquecer" que foge do mouse
- Cofre com senha secreta (2026)
- Cronômetro quântico em tempo real
- Personalização com nomes

## Surpresas adicionadas

- Campo para personalizar o nome dela e o seu
- Música oficial da faixa + sons gerados por Web Audio API
- Easter egg de 50 cliques
- Cláusula extra no contrato
- Design totalmente responsivo (mobile-first)
- Progress bar + navegação por dots
- Tema cyber-romântico com neon, ouro e espaço profundo

## Dica

Use fones de ouvido, preencha os nomes e viva a jornada completa até o pedido final.
